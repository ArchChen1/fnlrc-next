fnlrc 飞牛歌词补完器

让每一首歌
都有译文

把「只有原语言、单行显示、刮错、乱码、干脆没歌词」变成 原文 + 译文双行。 默认只预览、不写入，确认之后再动手。

支持本地文件夹、SMB 共享、映射盘符；网页版填挂载进容器的路径。

需要访问令牌

      

        这个服务不是从本机打开的，所以不会自动带上令牌。在服务器上执行下面这条命令拿到它：
        

docker logs fnlrc 2>&1 | grep -i token
        
或 fnlrc token
      

      
      

        令牌与 API key 同等重要 —— 拿到它就能触发扫描和写入。它只存在这台浏览器里。
      

      

        
        
      

    


    
    

      
选择音乐库

      

        填一个要补完歌词的音乐目录，先扫一次看看有多少歌。只读、不写入、不联网。
        网页版填挂载进容器的路径。
